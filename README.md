# Petualangan Santay — by Gunz Developer

Game survival 3D (Three.js) -> APK via Capacitor + GitHub Actions.

## Cara build APK
1. Upload semua isi folder ini ke repo GitHub (branch `main`).
2. Buka tab **Actions** -> workflow "Build APK Petualangan Santay" (jalan otomatis saat push, atau klik *Run workflow*).
3. Unduh `PetualanganSantay.apk` dari **Artifacts** atau halaman **Releases**.

## Kontrol
Joystick kiri = jalan, geser layar = lihat, ✊ = tebang/serang, ⤴ = lompat, 🏗️ = mode bangun, 🍖 = makan, 🎒 = tas (buat kapak/tombak).
PC: WASD, spasi, klik, B bangun, R putar, E aksi, F makan, I tas.
